# Dusty — Dust Recycler ♻️

Visual prototype of **Dusty**, an app that sweeps leftover wallet "dust" into the $DUSTY reward token.

**Prototype only.** Demo data, simulated wallet connection, no real transactions. Targets Base Sepolia (testnet). Not audited; not an offer to buy or sell anything.
