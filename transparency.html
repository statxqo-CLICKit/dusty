Admin powers (stated plainly)

The admin can: change the Recycler's per-quote and daily limits (never above the hard ceilings shown above), change the fee (never above 10%), change the quote signer and allowed dust tokens, pause or unpause, and grant or remove minters on the token. The admin cannot touch the reserve lock. Any admin change is an on-chain transaction anyone can see; handing the admin role to someone else takes a 2-day public delay.
